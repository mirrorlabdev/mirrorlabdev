## What I'm building — PLOT

> every AI novel app I tried gave me homework first — lorebooks, character sheets, an opening scene. that's outsourcing the AI's job to the user. and chatbots? that's talking. I wanted to read.
> — [me, on X](https://x.com/Kiha_Kwon/status/2084218733241798993)

PLOT writes interactive novels. Pick a genre — or type anything — and it writes a story that bends to every choice and keeps the thread as it grows.

- 40 languages
- Live on the web, Telegram, iOS and Android
- [plotai.app](https://plotai.app) · [blog](https://plotai.app/blog/)

The source is private. Most of the green squares above are PLOT.

## How I work

> people treat AI agents like machines that need to be controlled, rather than workers that need to be managed.
> …the job is not to eliminate every mistake. it is to keep mistakes reversible, observable, and recoverable.
> — [full post](https://x.com/Kiha_Kwon/status/2083912744424939869)

I run development like a small company — Claude Code and Codex are the staff, I'm the one who decides.

- **Agents write most of the code.** I set direction, judge the results, and decide what ships.
- **Review is sized to the damage it could do.** Anything touching production, payments or user data gets a hard gate; nobody approves their own deploy.
- **Every agent starts the day with no memory**, so the company's state lives in the repo: specs, decision logs, handoff notes.
- **Incidents become written rules**, so the next session — human or AI — starts from them.
